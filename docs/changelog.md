# Changelog

## Alpha 0.2.1 — Resource integration

- Added Blue Skies glass and sunstone alternatives for Ad Astra components
  and decorative lighting, preserving native quantities and metal costs.
- Added conservative Snowcap/frostmint cryogenic fuel recipes, pollen-assisted
  cave fertilizer and honey-residue sticky pistons.
- Connected native raw-food and Honey Slime lure tags. Blue Skies dungeon
  libraries can award native cave tablets without replacing existing loot.
- Added item tooltip hints for these optional uses. No new items or mandatory
  progression gates were introduced.

## Alpha 0.1 — Phases 2-4

- Added a native Blue Skies Everbright discovery milestone.
- Added a verified diopside exploration cue and the `kubejs:prism_lens`
  artifact recipe.
- Added Prism Lens language text, a 16x16 item texture, progression documentation,
  and automated graph/ID/pack validation.

## Alpha 0.2 — Final creative pass

- Added optional discovery milestones for the Moon, the Bumblezone, and the
  Primordial Caves without changing their native routes or progression.
- Reworked the Prism Lens icon in a vivid, high-contrast pixel palette and
  added the custom Fractured Cosmos advancement backdrop.
- Reframed the advancement text and player guide around parallel exploration
  threads; the Prism Lens recipe remains the Blue Skies / Ad Astra bridge.
