# Destination and story map

Rockets are reliable physical travel; rifts are colourful, impossible, and uncertain. The first story beat is a fracture on Earth, followed by Everbright/Everdawn, then the Moon's proof that the fracture reaches space, and finally Glacio's network origin.

Recurring visual grammar: broken circles for uncontrolled rifts, concentric stars for mapped destinations, dark glass with chromatic edges for technology, and a three-note anomaly pulse. Each destination gets one dominant hue, one impossible accent, one landmark, and one artifact.
